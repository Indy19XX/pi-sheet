# PI Sheet Call Assistant

A free seller-call script and Property Information Sheet for BOFSLO (buy owner-finance, sell lease option) investors.

**Open the app:** https://indy19xx.github.io/pi-sheet/

- Works in any modern browser on phone or computer — no login.
- Paste a listing's page text to fill price, beds, baths, sq ft, address and the owner's phone.
- Live call transcript in Chrome, Edge and Safari.
- Picks Path A / Path B and shows the next question to ask.
- Saves calls on your own device; download your call log as a spreadsheet, back up and restore.
- Add it to your home screen to use it like an app.
